# Smart Grocery Management System

A simple beginner-friendly grocery inventory management mini project.

## Features
- Add grocery products
- Select product category
- Store price and stock quantity
- Search products
- Low-stock indicator
- Delete products
- Dashboard statistics
- Data saved using browser LocalStorage

## Technologies
HTML, CSS, JavaScript

## How to Run
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` in a browser or use Live Server.
